# NIKITA web dashboard

Next.js 16 (App Router, Cache Components) + Tailwind 4. See the project
[`DEVELOPMENT.md`](../../DEVELOPMENT.md).

- `pnpm dev` — dev server on :3000; `/api/*` is proxied to `NIKITA_API_ORIGIN` (default `http://localhost:8000`)
- `pnpm typecheck` · `pnpm lint` · `pnpm build`
